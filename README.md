# Сравнительная лексикография феминитивов в русском и белорусском языках

**Электронный сравнительный словарь феминитивов в русском (37 лексических единиц) и белорусском (29 лексических единиц) языках.**

Проект представляет собой интерактивное веб-приложение для исследования словообразовательных моделей, грамматических особенностей и стилистической дифференциации феминитивов в двух близкородственных славянских языках.

---

## 🌟 Основные возможности и функции

1. **Два режима словаря (языковых корпуса)**:
   - **🇷🇺 Русский язык**: 37 лексических единиц с разметкой ударений, частей речи, словообразовательных суффиксов (`-к-`, `-ниц-`, `-иц-`, `-ш-`, `-ин-`, `-есс-`, `-ис-` и др.), производящих основ, грамматических и стилистических характеристик (нормативные, неологизмы, просторечные, устаревшие/историзмы).
   - **🇧🇾 Белорусский язык**: 29 лексических единиц с разметкой ударений, частей речи, моделей деривации (суффиксы `-к-`, `-іц-`, `-ін-`, `-ьн-` и др.), грамматических помет и стилистических комментариев (литературная норма, неологизмы медиа, традиционная и конфессиональная лексика).

2. **Интерактивные визуальные темы и баннеры**:
   - Тематическое оформление для каждого корпуса с эмблемами, парящими буквами и научными цитатами.
   - Поддержка **Светлой** и **Тёмной** темы с автоматическим сохранением выбора в `localStorage`.

3. **Умный поиск и навигация**:
   - «Живой» поиск без перезагрузки страницы.
   - Кросс-языковая нормализация букв: поиск корректно сопоставляет кириллические символы (`и` / `і`, `у` / `ў`, `е` / `ё`, `ъ` / `’`).
   - Виртуальная клавиатура спецсимволов: `[ ё ]`, `[ ъ ]`, `[ і ]`, `[ ў ]`, `[ ’ ]`.
   - Фильтрация по алфавиту активного словаря (динамический список букв).
   - Области поиска: везде, только в заглавных словах, в описаниях и словообразовательных моделях.
   - Избранное (закладки) с сохранением в памяти браузера.

4. **Адаптивный интерфейс**:
   - Полная поддержка мобильных телефонов, планшетов, ноутбуков и широкоформатных мониторов.

## 🔐 Режим чтения и Администрирование

### 1. Режим чтения (Гость)
- Доступен всем посетителям по умолчанию.
- Доступен полный просмотр, поиск, алфавитная фильтрация, добавление в избранное, копирование словарных статей и экспорт в JSON.
- Кнопки редактирования, удаления и добавления новых слов скрыты.

### 2. Режим Администратора
- Вход осуществляется через кнопку **«Вход»** в правом верхнем углу шапки сайта.
- **Логин по умолчанию**: `admin`
- **Пароль по умолчанию**: `admin123`
- *После успешного входа*:
  - В шапке появляется индикатор **«🛡️ Администратор»** и кнопка **«🔑 Пароль»** для смены пароля.
  - На каждой карточке слова появляются кнопки **«✏️ Редактировать»** и **«🗑️ Удалить»**.
  - В модальном окне подробной статьи доступна кнопка **«✏️ Редактировать»**.
  - Доступна кнопка **«+ Добавить слово»** с полной формой заполнения лингвистических параметров.
  - Доступна кнопка выхода **«Выйти»**.

## 🚀 Размещение на GitHub Pages

Сайт полностью автономен и готов к публикации на **GitHub Pages** (статический сайт без серверных зависимостей, Web APIs, `.nojekyll`, `404.html`).

### Пошаговая инструкция:

#### Шаг 1. Создание репозитория
1. Перейдите на [github.com](https://github.com) в свой аккаунт.
2. Создайте новый репозиторий (например, `feminitive-dictionary-ru-be`), выбрав **Public**.
3. Не создавайте файл README через интерфейс (он уже есть в проекте).

#### Шаг 2. Отправка файлов в репозиторий
Откройте терминал в папке проекта и выполните:
```bash
git init
git add .
git commit -m "Релиз сравнительного словаря феминитивов русского и белорусского языков"
git branch -M main
git remote add origin https://github.com/ВАШ_ГИТХАБ_ЛОГИН/feminitive-dictionary-ru-be.git
git push -u origin main
```

#### Шаг 3. Включение GitHub Pages
1. В репозитории на GitHub перейдите во вкладку **Settings** -> **Pages**.
2. В секции **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main`, папка `/ (root)` -> нажать **Save**.
3. Через 1–2 минуты сайт станет доступен по адресу:
   `https://ВАШ_ГИТХАБ_ЛОГИН.github.io/feminitive-dictionary-ru-be/`

## 💾 Сохранение изменений базы для всех пользователей

При добавлении, редактировании или удалении слов в браузере изменения сохраняются в `localStorage`. Чтобы зафиксировать их в исходном коде для всех пользователей:
1. Войдите как администратор.
2. Внесите необходимые изменения.
3. Откройте окно **«База данных / Экспорт»** -> вкладка **«Экспорт в JSON»**.
4. Нажмите зелёную кнопку **«Скачать dictionaries.js (для GitHub)»**.
5. Замените файл `data/dictionaries.js` в проекте скачанным файлом.
6. Отправьте коммит на GitHub:
   ```bash
   git add data/dictionaries.js
   git commit -m "Обновление словарной базы"
   git push
   ```
